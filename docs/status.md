## งานค้าง เรียงตามความสำคัญ

1. **ตั้งวันของรอบที่ใช้งานอยู่ใน `/admin` → รอบ** (ปิดลงทะเบียน และเปิดจับคู่/ประกาศผล) ถ้าไม่ตั้ง การ์ดช่วงลงทะเบียนจะไม่แสดงสองบรรทัดวันที่
2. **ทดสอบฟอร์มขอเพิ่มตำแหน่งกับ production จริง** ด้วยบัญชี LINE ที่ยังไม่เคยลงทะเบียน: เลือกตัวเลือกใน dropdown → ส่งฟอร์ม → เห็น modal ขอบคุณ → มีแถวใหม่ในตาราง `position_requests` (ยังไม่เคยลองส่งจริง; ตอนนี้ดูคำขอได้เฉพาะใน Supabase table editor ยังไม่มีหน้าแอดมิน)
3. **ทดสอบบนเครื่องจริงในแอป LINE:** แถบเมนูล่างเทียบ home indicator, หน้า login ใหม่, การเปิดแอปจากแชต LINE โดยตรง (log login ที่ทดสอบแล้วอาจไม่ได้มาจากแอป LINE), Flex card แจ้งคำขอติดต่อ, หน้าข่าว, flow ลบรายชื่อ/ยกเลิกคำขอ
4. **เปลี่ยนรูป cover ใน `/admin/news`:** เคยเปลี่ยนไม่ได้ สาเหตุที่แน่ชัดยังไม่พบ แก้ด้วยการย่อรูปฝั่งเบราว์เซอร์ + แสดง error + ปุ่มลบรูป ยังไม่ยืนยันว่าใช้ได้จริง ทดสอบบน Preview ได้
5. **วิธีทดสอบส่ง Flex card:** (A) ใช้ 2 บัญชีทดสอบผ่านแอป หรือ (B) สคริปต์ที่รันเองด้วย Messaging API token ยังไม่ตัดสินใจ
6. **จำกัดปุ่มโหมดทดสอบและ `/api/matches/dev`** ให้ใช้ได้เฉพาะ LINE user id ที่อนุญาต (เพื่อกันกรณีเผลอเปิด `NEXT_PUBLIC_DEV_TOOLS` ที่ Production) ยังไม่ตัดสินใจ
7. **หน้า `app/dev-preview-contacts/`:** ถูก commit อยู่ใน `main` ใช้เป็นหน้า mock ตรวจ UI ต้องตัดสินว่าจะเก็บหรือลบ (หน้า `app/dev-preview-*` ต้อง type check ผ่านเสมอ ไม่งั้น build บน Vercel ล้ม)
8. ทางเลือกที่ทำเพิ่มได้: แสดงหมวดข่าวบนหน้าแรกของแอป, `contactSummary` แยกตาม role, สร้าง LIFF app แยกสำหรับ Preview (ตอนนี้ใช้ `yokyai-local` ร่วมกับเครื่อง local ต้องสลับ Endpoint URL), ลบ branch เก่าที่ merge แล้ว

## ข้อจำกัดที่ควรรู้

- ยังไม่มี e2e test (unit test 133 ข้อ)
- Migration รันด้วยมือก่อน merge ทุกครั้ง (`npx supabase db push --dry-run --linked` แล้วค่อย `db push --linked` ใน branch ของ PR นั้น) ใช้จริงแล้วกับ 0034 และ 0035 ยังไม่ผูกกับขั้นตอน deploy อัตโนมัติ (เคยพลาด 2 ครั้ง: รายการโปรด, ข่าว) ถ้ารันตอนอยู่บน `main` ที่ยังไม่มีไฟล์ใหม่ CLI จะตอบว่า up to date ทั้งที่ยังไม่ได้รัน
- ตาราง `teachers` ยังเก็บฟิลด์เฉพาะครูไว้ในตารางเดียว ส่วน role ใหม่ใช้ตารางส่วนขยาย (ดู [adding-a-role.md](adding-a-role.md))
- Role `demo` มีไว้พิสูจน์โครงสร้าง ไม่เปิดให้ผู้ใช้จริง
- Preview เปิดสาธารณะ (ปิด Vercel Authentication เพื่อให้ LINE login เข้าได้) ปลอดภัยเพราะใช้ DB ทดสอบและไม่มี token ส่งข้อความ
